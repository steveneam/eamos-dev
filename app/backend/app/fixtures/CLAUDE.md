# fixtures/

Offline fixture data used when `USE_REAL_APIS=false`. Two subdirectories: tool-level fixtures and report-level fixtures.

## Subdirectories

| Directory | What | When to read |
| --------- | ---- | ------------ |
| `tools/` | JSON fixture responses for each data-fetch tool | Understanding mock data shape, debugging fixture mode |
| `reports/` | PDF and JSON fixture documents for patient report intake tests | Understanding report intake fixtures |
