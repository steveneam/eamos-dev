# rules/

ACMG evidence classification rules engine.

## Files

| File | What | When to read |
| ---- | ---- | ------------ |
| `base.py` | Abstract base classes for rules and evidence weights | Adding a new rule type or changing evidence scoring |
| `clinic_rules.py` | ACMG classification rules: PS, PM, PP, BA, BS, BP criteria | Changing pathogenicity classification logic |
