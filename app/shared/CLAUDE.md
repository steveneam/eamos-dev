## Files

| File | What | When to read |
| ---- | ---- | ------------ |
| `README.md` | Overview of shared directory purpose and usage | Understanding the shared contract |

| Directory | What | When to read |
| --------- | ---- | ------------ |
| `contracts/` | OpenAPI contract JSON (`backend-api.json`) — source of truth for request/response shapes | Changing API contract, checking type definitions |
| `demo-data/` | Demo data fixtures for offline and test use | Adding or modifying fixture data |
