# lib/

API client, TypeScript type definitions, and utility functions.

## Files

| File | What | When to read |
| ---- | ---- | ------------ |
| `api.ts` | API call functions: `variantLookup()`, report submission | Adding or changing API calls |
| `backend.ts` | TypeScript types matching FastAPI response schemas | Changing request/response shapes |
| `utils.ts` | Shared utility functions (className helpers, etc.) | Adding or modifying shared utilities |
