# ui/

Radix-based UI primitives. Shared across the application; modify with care as changes affect all usage sites.

## Files

| File | What | When to read |
| ---- | ---- | ------------ |
| `badge.tsx` | Badge component — status indicators | Changing status display |
| `button.tsx` | Button component with variants (default, ghost, outline) | Changing button styles or behaviour |
| `dialog.tsx` | Modal dialog component | Changing or adding modal UI |
| `tabs.tsx` | Tab navigation component | Changing or adding tabbed UI |
| `textarea.tsx` | Textarea input component | Changing text input UI |
