## Design decisions (autonomous)
- Delivery = laddered Measure→Conform→Enforce milestones, report-only first, dependency-ordered. Never flip a blocking gate onto a non-conforming repo; size Conform from measured count.
- Boundary ratchets (graphify replacement) must be GREEN + enforced BEFORE graphify-out/ deleted. → graphify-decommission milestone DEPENDS ON boundary-ratchet milestone.
- Web boundary ratchet = node guard script (reuse .mjs pattern), not a new vitest harness.
- Gateway choke point: single wrapper; request path = per-user+global caps; offline CLI path = operator/global token budget (don't force per-user cap on operator CLIs).
- grep-guard for Eamos = secrets + conflict-markers (NOT brand-hiding — Eamos is the private product repo).
- CI required-check name stability via aggregate job (needs+if:always()+explicit success assert), like Thalon `test`.
- Each gate 3-move; Enforce move conditional on Conform reaching zero.
