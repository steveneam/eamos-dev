# Eamos repo rot and refactor audit - 2026-06-30

Status: audit artifact. This pass did not delete files, mutate deploy/runtime state,
flip providers, download source data, or touch Supabase metadata/storage.

Frontend source-of-truth note: `app/web` is the active Next.js frontend.
`app/frontend` is a frozen Vite frontend reference retained only for historical
comparison until Steven approves an exact deletion or regeneration task.

## Scope and method

Reviewed the active backend, live Next frontend, frozen Vite frontend, docs/plans,
Supabase migrations, local scratch areas, and tracked data assets. The evidence
below comes from concrete `git ls-files`, `rg`, hash duplicate, line-count, and
targeted source reads.

Line counts below are measured with PowerShell `Get-Content | Measure-Object -Line`,
so they may differ slightly from editor counts that include blank-line handling.

## Executive findings

1. High: `app/web` and `app/frontend` are now competing frontend truths.
2. High: `/api/v1/search` is mounted but not wired in normal app construction.
3. High: several backend services have grown into package-sized modules.
4. High: Workbench/report frontend files are monolithic and duplicated across apps.
5. High: large clinical source assets are committed under `app/backend/data/source_assets`.
6. Medium: old plans still look executable and contradict the current Next.js app.
7. Medium: `.claude/` local agent/tooling files are tracked and likely stale.
8. Medium: ignored scratch directories are large but not tracked.
9. Medium: tracked verification screenshots and huge historical docs increase repo weight.
