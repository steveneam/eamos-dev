# docs/

Architecture guides, API research, design artefacts, and project admin. Reference only — not part of the build.

## Subdirectories

| Directory | What | When to read |
| --------- | ---- | ------------ |
| `architecture/` | API field guides (ClinVar, VEP, SpliceAI, Franklin), backend workflow diagram, solution brief | Implementing or debugging a data source; understanding the pipeline |
| `design/` | Design brief, copy pack, critique notes, Stitch prototype files and HTML screen | Frontend design decisions, brand voice, visual reference |
| `research/` | Narrowing options and problem-scope notes from pre-build phase | Understanding why the IRD/retinal scope was chosen |
| `sources/` | External source index — databases, papers, references | Finding a database reference or citation |
| `admin/` | Team notes, internal project coordination | Project admin questions |
