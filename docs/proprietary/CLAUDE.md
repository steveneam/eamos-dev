# docs/proprietary/

Catalogue Eamos-original scripts, CLIs, algorithms, and orchestration logic
here. Do not duplicate implementation code; point to the source files, tests,
API/CLI entry points, and plans.

When Codex or Claude creates a project-original system worth tracking, add or
update:

- `README.md` current entries table.
- One focused `<slug>.md` entry.
- `index.json` for the machine-readable catalogue.

Keep entries factual: what it does, why it is Eamos-original, source of truth,
verification, and caveats.

Every entry must include `Added:` and `Last updated:` metadata in local project
time (`YYYY-MM-DD HH:MM +zzzz - Agent`). Update the timestamp whenever the
proprietary script, skill, algorithm, CLI, service, or orchestration behavior
changes.
