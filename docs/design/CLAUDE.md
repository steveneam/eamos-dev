# design/

Design brief, copy pack, critique notes, and Stitch prototype files for the Eamos UI.

## Files

| File | What | When to read |
| ---- | ---- | ------------ |
| `brief.md` | Design brief — visual identity, layout principles, component goals | Starting frontend design work |
| `copy-pack.md` | UI copy: labels, CTAs, empty states, error messages | Writing or reviewing UI text |
| `critique.md` | Design critique notes from review sessions | Understanding design rationale and rejected alternatives |
| `research.md` | Design research notes — competitor analysis, reference UIs | Understanding design decisions |

## Subdirectories

| Directory | What | When to read |
| --------- | ---- | ------------ |
| `stitch/` | Stitch prototype files: design system JSON, HTML screen, prompt history | Reviewing the visual prototype, regenerating Stitch output |
