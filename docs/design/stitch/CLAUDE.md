# stitch/

Stitch AI prototype files: design system specs, semantic rules, and screen exports.

## Files

| File | What | When to read |
| ---- | ---- | ------------ |
| `design-style.md` | Style guide for Stitch — typography, colour tokens, spacing | Regenerating or updating the Stitch design |
| `design-system.md` | Human-readable design system documentation | Understanding design tokens and component rules |
| `design-system.json` | Machine-readable design system (Stitch input) | Regenerating Stitch output |
| `semantic-rules.json` | Semantic UI rules for Stitch component generation | Changing Stitch component behaviour |
| `state.json` | Stitch session state | Resuming or inspecting the Stitch session |
| `pre-approval-lock.md` | Locked design decisions — do not change without stakeholder sign-off | Checking which design decisions are frozen |

## Subdirectories

| Directory | What | When to read |
| --------- | ---- | ------------ |
| `desktop/` | Desktop screen exports: HTML prototype, PNG previews, prompt history | Reviewing or regenerating the desktop screen |
