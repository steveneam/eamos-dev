# desktop/

Stitch desktop screen exports and prompt history.

## Files

| File | What | When to read |
| ---- | ---- | ------------ |
| `screen.html` | Full HTML prototype of the desktop screen | Reviewing the interactive prototype |
| `screen.png` | Desktop screen screenshot (standard) | Quick visual reference |
| `screen-full.png` | Full-page desktop screenshot | Reviewing complete page layout |
| `prompt.md` | Initial Stitch generation prompt | Regenerating or understanding the original design brief |
| `edit-1-prompt.md` | First iterative edit prompt | Reviewing design evolution |
| `edit-2-prompt.md` | Second iterative edit prompt | Reviewing design evolution |
| `meta.json` | Stitch screen metadata | Stitch session management |
